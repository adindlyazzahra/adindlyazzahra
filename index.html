ⓘ Panduan Penggunaan Binder

🎀 Mengenal Binder

Binder ini digunakan untuk menyimpan dan mengatur koleksi artwork dalam bentuk kartu. Setiap sleeve memiliki empat slot kartu.

🖼️ Menambahkan Artwork

  • Klik ➕ Tambah Gambar untuk memilih satu atau beberapa gambar dari perangkat.
  • Klik slot kosong pada sleeve untuk mengisi slot tersebut dengan gambar.
  • Gunakan tombol panah Sebelumnya dan Berikutnya untuk berpindah halaman.
  • Klik + Halaman untuk menambahkan sleeve baru.

✨ Saku Favorit

Klik salah satu saku di sisi kiri untuk mengganti gambarnya. Gunakan tombol ✕ pada saku untuk menghapus gambar dari saku favorit.

📝 Detail dan Catatan Artwork

Klik kartu yang sudah terisi untuk membuka detailnya. Di sana kamu dapat mengubah judul, kategori, efek holografik, serta menulis catatan menggunakan Markdown. Perubahan disimpan melalui tombol simpan.

🌈 Kategori dan Efek Holografik

Pilih kategori untuk mengelompokkan artwork. Kamu juga dapat membuat kategori sendiri dan memilih warna. Efek holografik mengubah tampilan visual kartu di binder.

📦 Import dan Backup

  • 📥 Import ZIP digunakan untuk memuat koleksi dari file ZIP yang didukung. Untuk fail zip berisikan karya Adinda sendiri bisa didapatkan di sini.
  • 📦 Export / Backup ZIP digunakan untuk membuat salinan koleksi agar dapat disimpan sebagai backup.
  • Simpan backup secara berkala, terutama sebelum membersihkan data browser atau berpindah perangkat.

⚙️ Auto-Compress

Opsi Auto-Compress membantu mengurangi ukuran gambar saat ditambahkan. Klik ⚙️ Kualitas untuk mengatur resolusi maksimal dan kualitas kompresi.

♡ Tips: Data binder disimpan di penyimpanan browser pada perangkat ini. Export ZIP secara berkala agar kamu tetap memiliki salinan koleksi.

⚙️ Pengaturan Auto-Compress Gambar

Saat Auto-Compress aktif, foto kamera atau hasil scan beresolusi besar otomatis dikompres menjadi biner ringan agar binder tetap cepat saat menyimpan ratusan kartu.
